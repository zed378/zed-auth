# PF-03–05 — Parallel console primitive implementation

Implements the Button, Table and Form Field tasks in `TASKS/PHASE-F-FRONTEND-IMPLEMENTATION.md`, following `docs/UI-UX/07-COMPONENT-SPECIFICATION.md`, accessibility, responsive and form UX references.

- Button adds explicit disabled reasons and development warnings, plus an opt-in `ButtonSection` warning for duplicate primary actions. Existing callers remain compatible; missing reasons warn rather than throw.
- Table preserves stale rows on refresh errors, supports sortable headers, cursor controls, accessible row action menus and expandable secondary details. Large tables use browser content visibility while retaining rows in the DOM; this is rendering optimization, not DOM virtualization.
- Form fields share visible labels, associated descriptions and error announcements. Includes text, textarea, select, checkbox, radio, immediate switches and multi-value draft editing with timed undo.
- The workbench adds form states and input examples and displays stale Table data on error.

Validation: all 348 console tests pass across 24 files, including dedicated Button, Table and Form Field tests. Build, lint and whitespace checks pass. The first integrated run found duplicate secondary-column content; disclosures now mount detail content only when open, with a regression assertion. Browser geometry, assistive-technology behavior and large-table performance remain acceptance work. Tasks stay REVIEW; PF-02's remaining catalog entries are still pending.
