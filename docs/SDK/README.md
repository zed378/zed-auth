# Category: SDK

Client integration libraries (Go SDK, TypeScript SDK, React Auth Provider & Hooks) and HTTP gateway middleware specifications.

## Category Mandate

The `SDK/` directory defines **developer integration libraries**. It specifies official client SDKs, React integration hooks, and HTTP middleware packages for downstream service integration.
