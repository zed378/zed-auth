# Category: PLAN

Product intent, scope, requirements, roadmap, acceptance criteria, risk register, and feature specification templates.

## Category Mandate

The `PLAN/` directory defines **what** we are building and **why**. It establishes product scope boundaries, explicit functional requirements, implementation milestones, risk registers, and acceptance criteria. All technical architecture and implementation specs stem from requirements established here.
