# 06 - Feature Specification Template

> Category: **PLAN** (`docs/PLAN/`) &nbsp;|&nbsp; Status: Final specification &nbsp;|&nbsp; Owner: Platform Security & Engineering

## Purpose

Provide a standard template for writing new feature specifications in `MEMORY/specs/` or `docs/`.

## Category Mandate

Enforces consistency across feature design proposals.

## Key Topics To Specify

- Business objective & actors.
- Data model changes.
- API contract updates.
- Authorization rules & validation.
- Abuse cases & audit logging.
- Testing & rollback plan.

## Reference Architecture & Specification

Standard Template Sections:
1. Objective
2. Actors & Permissions
3. API Changes
4. Database Changes
5. Security & Abuse Cases
6. Acceptance Criteria
