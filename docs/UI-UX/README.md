# Category: UI-UX

Design direction, visual language, component specifications, management console page specs, responsive behavior, accessibility, and public site UX.

## Category Mandate

The `UI-UX/` directory defines the **user experience and design system** for the Management Console and Public Site. It specifies visual tokens, responsive behavior, accessibility compliance (WCAG 2.1 AA), motion design, and page layouts.
